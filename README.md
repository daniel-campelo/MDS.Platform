# MDS Studio Foundation 0.0.1

M0 foundation for the MDS ecosystem. This repository deliberately contains no Pattern, Graphics, Smart Size, production output, or customer/product domain modules.

See [M0 implementation notes](docs/M0-FOUNDATION.md) for scope, setup and current acceptance status. For the homologation workstation, use the repeatable [startup guide](docs/WORKSTATION-STARTUP.md).

The M1 identity boundary is documented in [Shared Identity contract](docs/SHARED-IDENTITY-CONTRACT.md). It deliberately does not create a separate Studio account system.
